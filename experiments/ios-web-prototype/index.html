Essai approbation SSH

Cinq étapes, dans l'ordre. À la fin, envoie le bilan.

1 Installer sur l'écran d'accueil

Dans Safari : Partager → « Sur l'écran d'accueil », puis rouvre la page depuis l'icône. Les notifications n'existent que dans ce mode.

2 Créer la passkey

Elle servira de verrou : sans Face ID, la clé SSH reste illisible.

3 Créer la clé SSH protégée

Une clé de signature est créée puis chiffrée avec un secret que seule la passkey fournit.

4 Signer

Face ID déverrouille la clé, qui signe une demande. À faire deux fois.

5 Notifications

Active-les, demande un envoi, puis verrouille l'iPhone. Touche la notification quand elle arrive.
